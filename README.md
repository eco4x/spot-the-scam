## Cybersecurity awareness workshop

[Spot the Scam: Cybersecurity Awareness for Small Businesses](articles/workshop.md) is a practical 45-minute session for small businesses and their staff, using fictional examples to explore scam warning signs, payment verification and protecting PINs and one-time codes. Suggested group size: up to 10. Date, format and price are open for discussion.

[Workshop details on the blog](https://spotthescamguide.blogspot.com/2026/11/spot-scam-practical-workshop-for-your.html) · [Visit the full blog](https://spotthescamguide.blogspot.com/)

The workshop provides awareness training, not a security audit or a guarantee against fraud.
